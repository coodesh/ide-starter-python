# Projeto inicial (Python 3.11)

Ponto de partida para a sua solução. O enunciado está na plataforma, ao lado da IDE.

- A aplicação de exemplo responde no preview (porta 3000).
- Para rodar os testes: `python -m unittest discover -s tests -v`
- O código fica em `app/` e os testes em `tests/`. Dependências vão em `requirements.txt`.

Fique à vontade para reorganizar o projeto e acrescentar dependências.
